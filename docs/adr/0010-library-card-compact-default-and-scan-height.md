# Library card compact：默认紧凑 + 紧凑态扫读限高

ADR 0007 把 **Library card compact** 定为默认展开。实际扫 Todo/Archive 时，默认展开备注/附件占高，且紧凑态标题换行仍把同列卡片扯成参差。现改为：**未记住偏好的文件夹默认紧凑**；已写入本机的展开/紧凑偏好保留（不清库）。**仅紧凑态**做扫读限高——馆藏标题最多两行、会话 meta 一行、超出省略，悬停原生提示看全文，同栅格行卡片强制等高；**展开态**不套限高，备注/附件仍完整展示。仍为手动切换，不恢复按条目数/视口自动折叠。

**Rejected:** 改默认时清空全部紧凑 prefs；展开态也裁切备注/附件；只靠行数裁切却不齐高；截断后不提供看全文手段；固定像素高硬切半行字作为主策略。
